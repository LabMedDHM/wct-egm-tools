# haema_EGM_publication
Python scripts for generating figures and tables for an evidence and gap map (EGM) for haematopoietic non-solid cancers, particularly acute myeloid leukaemia (AML) and precursor B-cell neoplasms (B-ALL/LBL), as defined by the WHO Classification of Tumours (WCT) of Haematolymphoid Tumours.
